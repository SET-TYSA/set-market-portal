Metodología y fuentes

Valor unitario = suma de FOB USD / suma de peso neto kg. Los registros reflejan país exportador, no necesariamente país de producción. No distinguen granel de envasado, orgánico de convencional, ni fecha de negociación. No son precios spot. El resultado de destinos puede omitir registros confidenciales o sin peso; el agregado mundial puede diferir. La API pública limita las respuestas a 500 filas; las respuestas truncadas no se utilizan.

Fuente: UN Comtrade, API pública. Comparación manual: POOLred. Próxima fase: cruce espejo con aduanas de destino, identificación de reexportaciones y actualización programada. No hay actualización automática instalada.
